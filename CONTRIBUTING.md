# Вклад в Skill

## Базовые правила

1. Изменения, касающиеся требований ioBroker, должны ссылаться на официальный первоисточник.
2. Не добавляйте в Skill непроверенные примеры API или CLI.
3. Изменение процедуры должно затрагивать одновременно `SKILL.md`, соответствующий workflow/reference и скрипт/шаблон, если проверку можно автоматизировать.
4. Любой пример должен явно указывать, где его нужно адаптировать под версию контроллера, шаблон генератора и конкретное устройство.
5. Не помещайте реальные секреты, токены, приватные сертификаты, адреса частных систем или пользовательские дампы объектов в репозиторий.

## Проверки перед PR

```bash
node scripts/validate-skill.mjs
bash -n scripts/run-adapter-checks.sh
node --check scripts/adapter-preflight.mjs
node --check scripts/check-object-dump.mjs
node --check scripts/release-preflight.mjs
```

## Источники

При обновлении ссылки фиксируйте, проверяли ли вы release/tag или `main/master`. Если используете изменяющуюся документацию, не копируйте в Skill большой фрагмент; опишите правило своими словами и оставьте ссылку.
