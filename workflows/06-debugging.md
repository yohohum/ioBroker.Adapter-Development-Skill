# Этап 6. Локальная отладка

## 1. Dev-server

Установи `@iobroker/dev-server` как devDependency (предпочтительно для проекта) либо используй глобально, как разрешено README.

Для локальной установки package scripts должен включать:

```json
{
  "scripts": {
    "dev-server": "dev-server"
  }
}
```

Затем из корня адаптера, где лежит `io-package.json`:

```bash
npm run dev-server setup
npm run dev-server watch
```

Проверь актуальные команды и опции в README `@iobroker/dev-server` перед применением.

## 2. Режимы

- `setup` — первичная настройка локальной ioBroker среды.
- `watch` — запуск адаптера с автоматической синхронизацией/restart при изменении кода.
- `run` — запуск среды для проверки Admin UI без автоматического запуска адаптера.
- `debug` — запуск с возможностью debugger attach; `--wait` при необходимости.
- `upload` — обновление установленной копии/метаданных, в частности после изменения `io-package.json`.
- `update` — обновление локальных js-controller/Admin до нужной тестовой версии.

Не запускай тот же экземпляр дополнительно вручную из Admin, если `dev-server watch` уже управляет запуском: можно получить `ADAPTER_ALREADY_RUNNING`.

## 3. Контроллер и Admin версии

Настрой dev-server на минимально поддерживаемые версии проекта и проверь, что адаптер не использует API, появившийся только в более новой версии. Затем проверь рекомендуемую/актуальную версию.

## 4. Сценарии

Минимальный smoke test:

1. Установить и открыть Admin.
2. Создать экземпляр адаптера.
3. Заполнить корректную конфигурацию.
4. Запустить экземпляр.
5. Проверить логи и `info.connection`.
6. Проверить создание device/channel/state.
7. Проверить чтение и каждую команду на тестовом устройстве.
8. Отключить устройство/сеть и проверить unreachable/reconnect.
9. Остановить адаптер и убедиться, что соединения закрыты.
10. Перезапустить и убедиться, что objects/config не повреждены.

## 5. Фиксация результата

В `docs/DEVELOPMENT_NOTES.md` сохрани:

- Node/controller/Admin versions;
- модель и firmware тестового устройства;
- точные шаги;
- результат и фрагменты безопасных логов;
- непроверенные функции.

## Критерии завершения

- [ ] Dev-server setup/watch работают.
- [ ] Минимальная поддерживаемая версия проверена.
- [ ] Admin UI работает.
- [ ] Проверены connection, commands, reconnect, stop.
- [ ] Нет утечек timers/sockets/listeners.
- [ ] Результаты воспроизводимы и задокументированы.
