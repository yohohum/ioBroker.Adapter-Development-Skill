# Changelog (архив старых версий)

Этот файл содержит архив записей changelog для старых версий, которые вышли за пределы последних пяти релизов в `README.md` (правило repochecker S6020).

Не переноси сюда **WORK IN PROGRESS** при каждом релизе: release-script (или ручной bump) превращает его в заголовок новой версии с датой в `README.md`. В этот архив попадают только самые старые записи, когда в changelog `README.md` уже остаются последние пять версий.

## Пример структуры

## 1.2.3 (2026-XX-XX)

- Исправлено ...
- Добавлено ...

## 1.2.2 (2026-XX-XX)

- ...
